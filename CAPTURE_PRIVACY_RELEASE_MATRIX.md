# Capture Privacy Release Matrix

Capture Privacy is supported only for configurations verified from a second participant's receiver view. An operating-system content-protection request by itself is not a pass.

Record one row for every released desktop version and meeting-app update.

For each row, verify the main window, overlay, scanner and settings. Move windows between displays, enable click-through mode, sleep and wake the computer, restart AllyX, and repeat after operating-system or meeting-app updates. Test window and tab sharing separately from entire-display sharing.

Public wording must say that Capture Privacy depends on the operating system and sharing application. Never claim a configuration is invisible, undetectable, or universally supported unless the matching row has receiver evidence for that exact release.
