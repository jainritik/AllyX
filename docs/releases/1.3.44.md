# AllyX 1.3.44 — local Apple Silicon test build

Adds overlay keyboard controls while the overlay is visible, including when it is unfocused or in click-through mode:

- Command/Ctrl + Shift + Up/Down: scroll the answer.
- Command/Ctrl + Shift + Left/Right: jump to the beginning/end.
- Command/Ctrl + Shift + P: toggle the local cursor.

Shortcuts are unregistered when the overlay hides or closes. Conflicts are shown in the overlay. The local cursor is hidden over rendered overlay content by default; the header button or P shortcut restores it. Disabled buttons no longer request a waiting cursor. Incoming streamed text preserves the current scroll offset.

This does not freeze or conceal a pointer independently composited by meeting software. No fake cursor or global pointer movement is implemented. Remote-viewer visibility has not been verified. Removing the CSS waiting cursor does not diagnose an OS-level unresponsive-app spinner.

192 automated tests, TypeScript, and source lint pass. The local installer is ad-hoc signed for testing. No hosted renderer changes are required. Public download links remain on 1.3.43 until a new public release is published.
