# AllyX 1.3.42 — macOS Apple Silicon test build

## Fixes

- Preserve verified screen-capture permission and guard concurrent scanner startup.
- Default to area capture; send full-display OCR through editable review before answering.
- Report microphone and meeting-audio state accurately after stopping capture.
- Transcribe shorter audio chunks with bounded concurrent uploads while preserving transcript order.
- Preserve queued questions, streamed answer continuations, and partial answers during recovery.
- Recover owned interview saves and resumable drafts; prevent heartbeat checks from starting another charged session.
- Settle generation usage on provider failure or cancellation and cancel upstream work.
- Bound payment-provider requests, including response-body reads, to 12 seconds.

## Verification and limits

187 automated tests pass, including interrupted streams, cancellation, stalled payment responses, and an answer exceeding 250,000 characters across eight continuation parts. TypeScript, source lint, and the production web build pass. Earlier live macOS testing covered manual answers, microphone input, area/full-display capture, resume, and interview saving. That live run preceded this final packaging and is separate evidence from the automated suite.

Independent meeting-audio transcription, physical network interruption, live very-long provider responses, Windows, and other macOS versions still require testing. Local Razorpay sandbox credentials were rejected with `Authentication failed`; checkout and refund validation remain blocked on valid credentials. No real payments were made.

## Installation and hosting

Open `AllyX-1.3.42-arm64.dmg`, quit AllyX, and replace the copy in Applications. The bundle is ad-hoc signed for local testing, not Developer ID signed or notarized. The app loads the hosted renderer at https://allyx.vercel.app; server fixes are deployed there rather than embedded in the DMG. Public download links remain on the existing published cross-platform release until new release assets are published.

Reproduce the local installer with `ALLYX_ADHOC_SIGN=true CSC_IDENTITY_AUTO_DISCOVERY=false npx electron-builder --mac --arm64 --config.electronDist=node_modules/electron/dist --config.directories.output=dist/latest-1.3.42 --config.extraMetadata.version=1.3.42 --publish never`. Package metadata stays aligned with the published cross-platform download version; the local build overrides its bundle version.
