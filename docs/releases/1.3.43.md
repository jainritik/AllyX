# AllyX 1.3.43 — webpage capture

Replaces the scanner's entire-display action with **Capture webpage content**. Select the browser window, then click the preview below its tabs, address bar, and bookmarks. Only pixels below that line are sent to OCR; other windows and the desktop are excluded. A slider allows fine adjustment. The captured image is the reviewed preview, not a later screenshot that might show a different page.

The crop is explicitly selected because browser toolbar heights vary. This is not automatic webpage-boundary detection and does not capture content below the visible viewport. Selected-area capture remains available. Confident OCR follows the existing automatic-answer path; low-confidence OCR still requires review.

Requires the 1.3.43 desktop build. Older builds show an update message and retain selected-area capture; they do not silently use their old display-capture API from the new scanner UI. Preview data expires after two minutes and is cleared when the scanner closes. Missing windows never fall back to a display capture.

Verification: 190 automated tests pass, including window-only source selection, exclusion of AllyX windows, pixel-scaled cropping, invalid crop rejection, stale preview rejection, and delivery through the actual native handlers. TypeScript and source lint pass. These tests do not establish live accuracy on every browser/OS.

Installers remain unsigned/ad-hoc-signed testing releases. The payment credentials and live-test limitations recorded for 1.3.42 still apply.
